# MDX Interactive Components

This post demonstrates the interactive components available in MDX. Try them out!

## Counter Component

The `<Counter />` component tracks state and responds to clicks:

<Counter initial={0} label="Click Counter" />

You can reset, increment, or decrement the count!

## Toggle Component

Use `<Toggle />` to switch between two states:

<Toggle label="Feature Switch" onText="Feature On" offText="Feature Off" />

Perfect for showing/hiding features or toggling settings.

## Tabs Component

Display tabbed content with `<Tabs />`:

<Tabs tabs={[
  {
    label: "React",
    content: "React is a JavaScript library for building user interfaces with components."
  },
  {
    label: "MDX",
    content: "MDX lets you write JSX in markdown files, combining markdown simplicity with React power."
  },
  {
    label: "Interactive",
    content: "All of this is interactive - state is preserved per user session, making for engaging blog posts!"
  }
]} />

## Dynamic Content

MDX supports JavaScript expressions inline:

- Current year: **{new Date().getFullYear()}**
- Today's date: **{new Date().toLocaleDateString()}**
- Random number: **{Math.floor(Math.random() * 100)}**

## How to Use These

In your `.mdx` files, simply use the components:

```mdx
<Counter initial={5} label="My Counter" />

<Toggle label="Enable Dark Mode" onText="Dark" offText="Light" />

<Tabs tabs={[
  { label: "Tab 1", content: "Content here" },
  { label: "Tab 2", content: "More content" }
]} />
```

## Creating Custom Components

Want to add more interactive components? 

1. Create a new file in `src/components/mdx/`
2. Mark it with `'use client'` (client component)
3. Export your component
4. Add it to the imports in `src/lib/utils.tsx`
5. Add it to the components object in `parseFileToReactWithMDX`

Then use it in any `.mdx` file! 🚀
