# MDX Interactive Test

This is a test of MDX interactivity! MDX lets you combine markdown with React. Below are some examples:

## Dynamic Content Example

The current year is: **{new Date().getFullYear()}**

You can also use inline code expressions like `{1 + 1 = 2}`.

## Markdown Features

MDX supports all standard **markdown** features:

- Lists
- **Bold** and *italic*
- `Code blocks`
- [Links](https://example.com)

### Code Blocks

Here's some syntax-highlighted code:

```javascript
function hello() {
  console.log("Hello from MDX!");
  return true;
}
```

## React Integration

With MDX, you can directly embed React components. For custom interactive components, 
they can be passed to your blog renderer component.

This example shows how MDX works with your blog system - you get the power of markdown
with the ability to use React expressions and components!

---

**Next steps**: To add fully custom interactive components, you may want to:
1. Create reusable React components in your `src/components/` folder
2. Pass them to the MDX renderer 
3. Use them anywhere in your MDX content
